# Schema Quality 100 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将 Winning Adventure Global 可控的 Schema 质量从 65/100 提升到 100/100：语法有效、事实一致、实体唯一、页面类型正确，并有自动回归检查。

**Architecture:** 用 `lib/schema.ts` 作为 Organization/Person/Service/Article 的唯一事实源，现有 React Schema 组件只负责把 builder 结果输出为 JSON-LD。全站只有一个 Organization `@id`，所有 Service、Article 和 Person 通过 `@id` 连回该实体。未核实的 foundingDate 和 geo 先删除，不使用猜测值。

**Tech Stack:** Next.js 16 App Router、React 19、TypeScript、JSON-LD/Schema.org、Jest + ts-jest。

---

## 100 分验收标准

1. sitemap 中每个可索引页的 JSON-LD 都能解析，0 个相对 URL，0 个废弃类型。
2. 全站 Organization 只有一个稳定 `@id`: `https://www.winningadventure.com.au/#organization`。
3. 没有矛盾的 foundingDate、geo、Person 或 offer URL。
4. 所有 Service `provider` 引用 Organization `@id`。
5. 所有 Article 都有绝对 image URL、publisher `@id`、可解析日期和真实 author `@id`。
6. 不存在无效 `timeToRead`、虚假 SearchAction、商业 FAQPage、自利性 AggregateRating 或虚假城市 LocalBusiness。
7. `npm run lint`、`npx jest --runInBand` 和 `npm run build` 通过；构建后抽查页面通过 Schema 回归脚本。

**Step 3: 实现最小 builder**

`lib/schema.ts` 导出：

```ts
export const SITE_URL = 'https://www.winningadventure.com.au'
export const ORGANIZATION_ID = `${SITE_URL}/#organization`
export const WEBSITE_ID = `${SITE_URL}/#website`
export const ANDY_ID = `${SITE_URL}/about#andy-liu`

export function buildOrganizationSchema() {
  return {
    '@context': 'https://schema.org',
    '@type': ['Organization', 'LocalBusiness'],
    '@id': ORGANIZATION_ID,
    name: 'Winning Adventure Global',
    legalName: 'WINNING ADVENTURE GLOBAL PTY LTD',
    url: `${SITE_URL}/`,
    logo: { '@type': 'ImageObject', url: `${SITE_URL}/logos/logo.png` },
    address: {
      '@type': 'PostalAddress',
      streetAddress: '5/54 Melbourne St',
      addressLocality: 'North Adelaide',
      addressRegion: 'SA',
      postalCode: '5006',
      addressCountry: 'AU',
    },
    telephone: '+61-416-588-198',
    email: 'info@winningadventure.com.au',
    identifier: [
      { '@type': 'PropertyValue', propertyID: 'ABN', value: '94 697 886 150' },
      { '@type': 'PropertyValue', propertyID: 'ACN', value: '697 886 150' },
    ],
    areaServed: { '@type': 'Country', name: 'Australia' },
    founder: { '@id': ANDY_ID },
    hasOfferCatalog: {
      '@type': 'OfferCatalog',
      name: 'China Sourcing Services',
      url: `${SITE_URL}/services`,
    },
  }
}
```

`buildServiceSchema()` 接受 `name/description/url/areaServed/serviceType`，并始终输出 `provider: { '@id': ORGANIZATION_ID }`。不添加无真实价格的 Offer。
